Contributing and credits

How to contribute, report problems, and who built what Maestrix is based on.

Contributing#

Contributions are welcome. Start with CONTRIBUTING.md and, for architecture notes written for coding agents, CLAUDE.md and docs/index.md in the repository.

Practical advice:

  • Open an issue first for anything larger than a small fix.
  • Keep pull requests focused, and add a regression test for every bug you fix.
  • Run the Swift and Python tests before opening a PR, and run GUI tests only under Xvfb.
  • Report security problems privately, following SECURITY.md.

Roadmap#

Planned work and focus areas are tracked in docs/roadmap.md. Known gaps on Linux today include the arrow and line drawing tools, a few of the node action buttons of the macOS app, and the second phase of Remote SSH.

Credits#

  • Euller: development and adaptation of Maestrix for Linux.
  • OpenMaestri and its contributors: the macOS codebase and inherited features, including the icon in this repository.
  • Original Maestri: product, concept and interface reference.
  • Libraries and dependencies keep their own licenses and attributions.
