Canvas and nodes

The infinite canvas, the node types you can place on it and how to move around.

The canvas is an infinite 2D surface. Everything you work with is a node placed on it, and nodes can be joined by ropes.

Node types#

Node What it is Create it with
Terminal A shell or an AI agent running in a VTE terminal. T, Ctrl+N, or the toolbar
Note A Markdown sticky note with a raw and a formatted view. It can also point to an existing file. Toolbar, or drop a text file on the canvas
File Tree A folder browser with Git badges. Toolbar, or drop a folder on the canvas
Portal An embedded browser (WebKitGTK) that agents can drive. P, or the toolbar
Text label Free text on the canvas. Toolbar
Drawings Rectangle, ellipse and diamond shapes. Toolbar → Draw

Not ported yet

The arrow and line drawing tools of the macOS app are not available on Linux yet.

Dropping other files on the canvas (images, PDFs, video) opens them in a read-only portal.

Every node has a header with its icon and title, a close button, and can be moved, resized and locked. A title can be renamed in place. Terminal names are unique within a workspace; see Terminals and agents.

Ropes (connections)#

A rope links two nodes. Ropes are drawn with a physics simulation and settle after you move a node. Ropes also carry permissions: a terminal can only see and address the terminals, notes and portals it is connected to.

  • Select a node and press L to start a connection, then click the target.
  • A terminal can be connected to another terminal, a note, or a portal. Notes and portals can also be linked to each other.

Navigating#

Action How
Pan Drag the empty canvas, or scroll
Zoom Ctrl+scroll, Ctrl+=, Ctrl+-, reset with Ctrl+0
Center the selected node \
Jump to the Nth terminal Ctrl+1 … 9
Select several nodes Drag a selection box, or Ctrl+A
Delete the selection Delete, or Ctrl+W (from inside a terminal use Ctrl+Shift+W)
Copy / paste elements Ctrl+C / Ctrl+V; works across workspaces

The bottom-right controls hold the Ground / Floors button (Floors), the minimap and the zoom control.

Alignment and background#

While you drag, nodes snap to alignment guides. Toggle snapping with Ctrl+; or in Preferences → General. The canvas background can be a dot grid, a solid colour or transparent.
